Requesting access

Callista is invitation-only and granted per email address. If you would like access, write with:

  • the email address you want it granted to — this is the one you will sign in with, so pick the mailbox you actually read
  • your name and affiliation
  • roughly what you want to use it for

Request access by email.

Reporting a problem

Useful things to include, in rough order of how much they help:

  • the question you asked, as you typed it
  • what came back, and what you expected instead
  • the publication you were looking for, if you know it exists
  • the address you signed in with, if it is a sign-in problem

Searches that return nothing are logged and reviewed, so a question the library should have answered and did not is worth reporting even if you found it another way.

Report a problem.
