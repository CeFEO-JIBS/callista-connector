Install Callista

About a minute, once. You need a Claude account and an invitation to Callista at the email address you will sign in with.

Before you start

Custom connectors are available on Claude Pro, Max, Team and Enterprise. On Team and Enterprise a workspace admin may need to allow it first.

The connector URL

You will be asked for this. Copy it exactly:

https://mcp.familybusiness.se/callista

Steps

  1. Open Claude in a browser at claude.ai and sign in.

    Connectors are added from the web app. Once added they work in the desktop and mobile apps too.

  2. Go to Settings → Connectors, then choose Add custom connector at the bottom of the list.
  3. Paste the URL above. Name it Callista if you are asked for a name. Confirm.
  4. Sign in with your email. A window opens asking for your address. Use the address your invitation was sent to — access is granted per address, so a different one will be turned away even if it is yours.
  5. Enter the six-digit code. It arrives by email within a few seconds and expires after a few minutes.

    The code is sent from noreply@fbdashboard.org, the shared sending address for these connectors. That is expected — it is not phishing.

  6. Done. Callista appears in your connector list. Start a new chat and ask it something.

Check it works

In a new chat, ask:

“Using Callista, what does the WIFU library say about Beiräte in family firms? Give me the three most relevant publications.”

You should get titles, years and links to wifu.de. If Claude says it has no such tool, the connector is not enabled for that chat — check the connector toggle in the chat’s tools menu.

If something goes wrong

  • “Not on the list.” The address you entered has not been granted access. Try the exact address your invitation went to, or ask us.
  • No email. Check spam for noreply@fbdashboard.org. Codes expire after a few minutes — start again from Claude to get a fresh one.
  • “Too many attempts.” Five wrong codes ends that sign-in attempt. Start again from Claude.
  • It worked and then stopped. Access is re-checked on every request, so a withdrawn or expired grant takes effect immediately. If that is unexpected, tell us.
