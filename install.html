Install Callista

About a minute, once. You need a Claude account and an invitation to Callista at the email address you will sign in with. There is a second, optional minute at the end: the Callista skill, which teaches Claude how to read the library it has just been given.

Before you start

Custom connectors are available on Claude Pro, Max, Team and Enterprise. On Team and Enterprise a workspace admin may need to allow it first.

The connector URL

You will be asked for this. Copy it exactly:

https://mcp.familybusiness.se/callista

Steps

  1. Open Claude in a browser at claude.ai and sign in.

    Connectors are added from the web app. Once added they work in the desktop and mobile apps too.

  2. Go to Settings → Connectors, then choose Add custom connector at the bottom of the list.
  3. Paste the URL above. Name it Callista if you are asked for a name. Confirm.
  4. Sign in with your email. A window opens asking for your address. Use the address your invitation was sent to — access is granted per address, so a different one will be turned away even if it is yours.
  5. Enter the six-digit code. It arrives by email within a few seconds and expires after a few minutes.

    The code is sent from noreply@fbdashboard.org, the shared sending address for these connectors. That is expected — it is not phishing.

  6. Done. Callista appears in your connector list. Start a new chat and ask it something.

Check it works

In a new chat, ask:

“Using Callista, what does the WIFU library say about Beiräte in family firms? Give me the three most relevant publications.”

You should get titles, years and links to wifu.de. If Claude says it has no such tool, the connector is not enabled for that chat — check the connector toggle in the chat’s tools menu.

Add the Callista skill

Optional, and worth the extra minute. The connector gives Claude the library; the skill tells it how to read it — to answer as a librarian of one institution rather than as the field, to keep the register of a Praxisleitfaden apart from that of a study, to carry the German term alongside the English, and to say so plainly instead of answering from memory when the connector is not reachable.

Download the skill (ZIP, 4 KB)

  1. Download the file above and leave it zipped. Claude wants the archive, not its contents.
  2. Check Settings → Capabilities. Code execution and file creation has to be on, or skills will not run. On Team and Enterprise a workspace admin may need to allow Skills first.
  3. Go to Customize → Skills and upload the ZIP.
  4. Done. Claude reaches for the skill on its own when a question is about WIFU, and you can always call it by name: “Callista, …”.

Why there is no one-click install

Claude has no install-from-a-URL for skills. A skill is a file you upload to your own account, and no web page can put one there for you — so a download button is as close as this gets. The connector above and the skill here are separate things, and each is installed in its own place: the connector under Connectors, the skill under Skills. The skill is worth little without the connector; it will tell you so rather than improvise.

In Claude Code instead? Unzip it into your personal skills folder:

curl -fsSL https://callista.familybusiness.se/callista-connector.zip -o /tmp/callista-skill.zip && unzip -oq /tmp/callista-skill.zip -d ~/.claude/skills/

If something goes wrong

  • “Not on the list.” The address you entered has not been granted access. Try the exact address your invitation went to, or ask us.
  • No email. Check spam for noreply@fbdashboard.org. Codes expire after a few minutes — start again from Claude to get a fresh one.
  • “Too many attempts.” Five wrong codes ends that sign-in attempt. Start again from Claude.
  • The skill uploaded but Claude ignores it. Check that it is switched on under Customize → Skills, and that Code execution and file creation is enabled under Settings → Capabilities. A skill that is off, or an account without code execution, produces no error — just ordinary answers.
  • It worked and then stopped. Access is re-checked on every request, so a withdrawn or expired grant takes effect immediately. If that is unexpected, tell us.
